¿Qué es el proyecto?

Herramienta visual y colaborativa de gestión de proyectos y tareas. Organiza el trabajo en un tablero con columnas y tarjetas para seguir el progreso en equipo.

  • ◆ Proyectos gestionados por miembros con roles diferenciados (OWNER · ADMIN · MEMBER).
  • ◆ Columnas personalizables que contienen tarjetas de tarea ordenadas según el estado del trabajo.
  • ◆ Disponible como aplicación web, móvil y de escritorio mediante PWA (Progressive Web App).

Dark / Light mode automático
  • Se adapta a la preferencia del sistema operativo del usuario — cero configuración
  • @media (prefers-color-scheme: dark) redefine los tokens CSS — un único punto de cambio para toda la app
  • color-scheme: light/dark — inputs, selects y scrollbars nativos también se adaptan
  • Sin librerías de theming externas — implementado íntegramente con CSS custom properties
Responsive y Scroll Snap
  • En móvil las columnas del kanban se encajan al deslizar — solo CSS, sin JavaScript
  • En escritorio: columnas fijas lado a lado.
