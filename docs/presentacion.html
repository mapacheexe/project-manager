¿Qué es el proyecto?

Aplicación web colaborativa de gestión de proyectos basada en metodología Kanban. Inspirada en Trello y Jira, construida desde cero con tecnologías modernas del sector.

  • ◆ Registro e inicio de sesión seguro con JWT
  • ◆ Crear proyectos y añadir miembros con rol
  • ◆ Definir etapas (columnas) personalizadas
  • ◆ Crear, editar, mover y eliminar tareas
  • ◆ Instalable como PWA en cualquier dispositivo
  • ◆ Responsive: móvil con scroll snap, escritorio

Modelo de datos
Flujo de autenticación JWT
Autenticación sin estado
  • El servidor no guarda ninguna sesión en base de datos
  • El token contiene el userId y la expiración, firmado con HMAC-SHA256
  • Cada petición se verifica solo por firma, sin consultar la BD
  • Cualquier instancia del servidor puede validarlo
Decisiones técnicas
JWT sin sesiones
  • El servidor no guarda estado — cualquier instancia puede validar el token
  • Sin tabla de sesiones en BD
  • Preparado para escalar horizontalmente
Por qué Angular
  • Framework completo — router, formularios y cliente HTTP incluidos sin configurar nada
  • Construido en TypeScript — tipado fuerte sin configuración extra
  • Signals estables desde v17 para reactividad moderna
Por qué Spring Boot
  • Spring Security integrado — autenticación y autorización sin librerías extra
  • Java tipado: el compilador detecta errores antes de ejecutar
  • JPA elimina el SQL repetitivo manteniendo control total
Liquibase + Hibernate
  • Hibernate gestiona las consultas en tiempo de ejecución — traduce objetos Java a SQL
  • Liquibase gestiona la estructura — crea y evoluciona las tablas de forma versionada
SCSS propio frente a Tailwind
  • Control total sobre el diseño sin depender de un framework CSS
  • Variables CSS para dark/light mode con una sola línea
  • El HTML no se llena de clases utilitarias
PWA frente a app nativa
  • Una sola base de código para web, móvil y escritorio
  • Sin pasar por tiendas de aplicaciones
  • Se actualiza automáticamente al publicar nueva versión
Tests y calidad
GitHub Actions
  • 2 jobs paralelos en cada push a main — frontend y backend se verifican de forma independiente
  • El build falla si un test falla o la cobertura baja del umbral
npm test -- --watch=false ./mvnw verify
JUnit 5 · Mockito · H2
  • Tests ejecutan contra BD H2 real — sin mocks de persistencia
  • Nomenclatura BDD: givenX_whenY_thenZ — cada test documenta un comportamiento
  • JaCoCo bloquea el build si la cobertura baja del 80%
Vitest
  • vi.useFakeTimers — controla el tiempo para testear comportamiento asíncrono
  • Cubre auth service, interceptor, guard y toast service
  • Convención describe / it — tests legibles sin contexto extra
Progressive Web App (PWA)
Service Worker
  • Script que el navegador instala en segundo plano
  • Intercepta las peticiones de red y sirve recursos cacheados
  • Permite que la app cargue aunque la red sea lenta o inexistente
  • Generado automáticamente por @angular/pwa
Web App Manifest
  • Archivo JSON que describe la app: nombre, icono, color de tema
  • Le dice al navegador cómo comportarse al instalarse
  • Activa el banner "Instalar" en Chrome y Safari
